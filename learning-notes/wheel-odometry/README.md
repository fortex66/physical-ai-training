# 바퀴 오도메트리와 비홀로노믹 주행

**바퀴 오도메트리는 바퀴의 회전량을 누적해 로봇의 위치와 방향을 추정하는 방법이다.**
차동 구동 운동학을 로봇 명령 생성에 사용했다면, 오도메트리는 실제 바퀴 측정값에서 이동을 추정하는 방향으로 사용한다.

## 회전량 → 이동량 → 포즈

바퀴 반지름 R, 좌우 간격 L과 바퀴 각도 변화량 Δφ를 사용한다.

$$
\Delta s_L=R\Delta\phi_L,\qquad \Delta s_R=R\Delta\phi_R
$$

$$
\Delta s=(\Delta s_R+\Delta s_L)/2,\qquad
\Delta\theta=(\Delta s_R-\Delta s_L)/L
$$

작은 시간 구간에서 중간 방향으로 위치를 갱신하면 다음과 같다.

$$
x\leftarrow x+\Delta s\cos(\theta+\Delta\theta/2)
$$

$$
y\leftarrow y+\Delta s\sin(\theta+\Delta\theta/2),\qquad
\theta\leftarrow\theta+\Delta\theta
$$

바퀴 각도는 rad, 거리·바퀴 반지름·간격은 m다.
각도 차이에서 구한 이동량에 시간 간격을 다시 곱하지 않는다.
16번은 실제 관절 각도를 사용하지만, 실제 로봇에서는 주로 엔코더로 회전량을 읽는다.

## 왜 오차가 생기는가?

| 요인 | 영향 |
|---|---|
| 바퀴 미끄러짐 | 바퀴는 회전해도 예상만큼 이동하지 않음 |
| 반지름·좌우 간격 오차 | 거리 또는 회전량 환산이 달라짐 |
| 관절·엔코더 부호와 각도 래핑 | 회전량을 잘못 해석할 수 있음 |
| 초기 위치·방향 차이 | 비교 좌표 기준이 어긋남 |
| 적분·측정 오차 | 주행하면서 오차가 누적될 수 있음 |

추정값이 실제 위치와 다르다고 모든 원인을 미끄러짐으로 단정하지 않는다.
특히 시작 직후부터 큰 오차가 보이면 초기 기준과 좌우 바퀴 변화량·부호를 먼저 함께 확인할 필요가 있다.

## 오도메트리는 절대 위치 측정이 아니다

오도메트리는 시작 포즈를 기준으로 이동량을 누적하는 추정이다.
실제 로봇에서는 IMU·카메라·LiDAR 등을 결합해 자세·위치 추정을 개선할 수 있다.
16번의 비교 기준값은 시뮬레이터 내부의 실제 위치이며, 센서로 얻은 위치 측정값과 구분한다.

## 좌표 기준과 거리의 의미

환경 기준 위치와 비교하려면 월드 위치에서 환경 원점을 제거한다.
하지만 초기 방향이 다르면 회전까지 고려하고, 오도메트리의 초기 포즈도 맞춰야 한다.
위치 오차와 방향 오차는 서로 다른 지표다.

중심 이동량의 절댓값을 누적한 주행 거리와 출발점에서의 직선 변위도 다르다.
원점을 돌아오는 주행은 변위가 작아도 누적 거리는 크다.

## 비홀로노믹과 경로 제어

JetBot 같은 차동 구동 로봇은 옆으로 바로 이동할 수 없으며 방향을 바꿔 전진·후진해야 한다.
이처럼 이동에 구속이 있는 방식이 비홀로노믹 주행이다.
메카넘·옴니 휠 플랫폼은 구성에 따라 몸체의 전후·좌우 속도와 회전을 독립적으로 명령할 수 있다.

시간 기준 속도 시퀀스는 실제 위치 오차를 보정하지 않는다.
폐루프 위치·경로 추종에서는 추정 포즈와 목표를 비교해 v·ω 명령을 다시 계산한다.
오도메트리를 읽는 기능과 피드백으로 경로를 따라가는 기능은 구분한다.
