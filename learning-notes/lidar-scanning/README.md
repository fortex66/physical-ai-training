# 2D LiDAR와 스캔 데이터 해석

**LiDAR는 여러 방향의 거리 측정으로 주변 표면의 배치를 파악하는 센서다.**
18번은 실제 레이저의 모든 특성을 모델링하기보다 RayCaster로 정적 메시와 광선의 교차를 계산하는 2D 스캔 예제다.

## 방향과 거리

각 광선에는 센서 기준 방향과 측정 거리가 있다.
수평 360°를 1° 간격으로 측정하면 이번 예제에서는 360개 광선을 사용한다.
가까운 벽 방향은 짧은 거리, 먼 벽 방향은 긴 거리로 나타난다.

월드 기준 교차점 `ray_hits_w`와 센서 위치 `pos_w`에서 차이 벡터의 크기를 구하면 거리가 된다.
교차점 좌표의 x·y·z 값 중 하나를 그대로 거리로 사용하는 것은 아니다.

## 좌표계

| 표현 | 의미 |
|---|---|
| 월드 교차점 | 장면의 어느 위치에 광선이 닿았는가? |
| 센서 기준 방향 | 로봇 앞·뒤·왼쪽·오른쪽 중 어느 방향인가? |
| 측정 거리 | 센서에서 표면까지 얼마나 떨어져 있는가? |

로봇이 회전하면 정적인 벽도 센서 기준 방향이 달라진다.
지도와 스캔을 겹쳐 표시하려면 센서·로봇·환경·월드의 변환을 맞춰야 한다.

18번의 극좌표 그래프는 전방 0°를 위쪽에, 왼쪽 +90°를 반시계 방향에 표시한다.
이 각도 규약과 광선 배열의 순서도 일치해야 한다.

## 유효값과 측정 대상

광선이 지정 메시와 교차하지 않으면 무한대가 나올 수 있다.
최소·평균 거리 계산에는 유효값만 사용하고, 표시용 대체값을 실제 측정과 혼동하지 않는다.
센서 사거리, 그래프 축 범위와 미교차 표시값은 각각 다른 설정이다.

RayCaster의 대상 메시 설정과 PhysX 물리 충돌 설정도 별개다.
측정 대상에 포함됐다고 자동으로 로봇 충돌 형상이 설정되는 것은 아니다.
이 예제의 기본 RayCaster 구성은 정적 미로 메시를 대상으로 한다.

## 스캔·회피·SLAM의 역할

| 기능 | 역할 |
|---|---|
| 스캔 | 각 방향의 거리와 교차점 읽기 |
| 장애물 회피 | 스캔 등의 정보를 이용해 충돌을 피하도록 이동 명령 변경 |
| SLAM | 센서 정보로 지도를 만들면서 자기 위치를 추정 |

18번은 스캔 결과를 시각화하고, 알려진 위치와 Waypoint로 주행한다.
스캔을 제어 입력에 연결한 장애물 회피나 SLAM은 구현하지 않는다.
또한 최소 광선 거리가 로봇 몸체 전체의 충돌 여유와 같다고 볼 수는 없다.
