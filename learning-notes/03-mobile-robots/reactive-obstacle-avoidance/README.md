# 반응형 장애물 회피

**반응형 회피는 현재의 장애물 정보에 따라 이동 명령을 즉시 바꾸는 방식이다.**
19번은 목표 추적과 장애물 회피를 거리 조건으로 선택하는 규칙 기반 예제다.

## 역할 분담

| 기능 | 질문 |
|---|---|
| 장애물 정보 획득 | 장애물이 어디에 있고 얼마나 가까운가? |
| 회피 판정 | 현재 명령을 바꿔야 하는가? |
| 회피 제어 | 감속·회전 방향과 속도를 어떻게 정할까? |
| 목표 추적 | 장애물에서 멀어졌을 때 어디로 갈까? |

19번은 저장된 박스 중심 좌표와 시뮬레이터 위치로 거리를 계산한다.
LiDAR·카메라로 장애물을 감지하거나 지도를 추정하지 않는다.
실제 로봇에서는 적절한 센서·위치 추정 정보가 필요하다.

## 거리와 회피 명령

가장 가까운 장애물 중심까지 거리가 임계값보다 작으면 AVOID로 전환한다.
장애물 반대 방향으로 회전하고 거리에 따라 전진 속도를 줄인다.
거리 조건을 벗어나면 NAV로 돌아가 목표 방향을 추종한다.
목표 반경 안에 들어가면 DONE으로 정지한다.

중심 거리, 표면까지의 센서 거리, 로봇 외형 전체의 충돌 여유는 다르다.
안전한 통과를 판단하려면 로봇·장애물의 형상과 구동 응답도 고려해야 한다.

## 전역 계획과 차이

반응형 회피는 순간적인 명령 변경이다.
전역 경로 계획은 장애물 배치를 고려해 목표까지의 경로를 구성한다.
직선 마커를 그렸다고 장애물 없는 경로를 계산한 것은 아니다.
두 기능을 함께 사용할 수 있지만 역할은 구분한다.

## 경계 전환·정체

진입과 해제에 같은 거리 임계값을 쓰면 경계에서 모드가 반복 전환될 수 있다.
가까운 장애물이 바뀌면 회피 방향도 갑자기 바뀔 수 있다.
좁은 통로나 복잡한 배치에서는 목표 추적과 회피가 충돌해 정체될 가능성도 있다.

히스테리시스는 진입·해제 임계값을 다르게 정해 잦은 전환을 줄이는 방법이다.
실제 센서 입력, 형상 기반 여유 거리, 경로 계획과 결합하는 것도 확장 방향이다.
이 기능들은 19번 원본에 이미 구현된 것으로 해석하지 않는다.
