# 그림으로 보는 강화학습과 20장 실행 구조

**20장은 강화학습 환경을 실행하는 코드이며, 정책 신경망의 가중치를 학습하는 코드는 아직 포함하지 않습니다.**
아래 그림은 실제 PPO 학습 구조와 20장의 현재 실행 구조를 구분해 보여줍니다.
이미지는 다운로드 없이 이 페이지에서 바로 볼 수 있습니다.

## 1. 실제 강화학습의 전체 구조

![환경·Actor·Critic·경험 수집·PPO·체크포인트의 관계](01-training-overview.png)

위쪽에서는 정책이 행동하고 환경이 결과를 반환합니다.
경험을 일정량 모은 뒤 PPO가 Actor와 Critic의 가중치를 업데이트하고, 바뀐 정책으로 다시 경험을 수집합니다.
보상 한 번을 받는 것과 학습 업데이트 한 번이 같은 단위는 아닙니다.

## 2. 정책 모델은 어떻게 구성되는가?

![Actor와 Critic의 관측·은닉층·출력 구성](02-actor-critic-model.png)

24장 Cartpole의 실제 설정인 은닉층 `[32, 32]`를 예시로 사용했습니다.
Actor의 행동 분포에는 평균을 출력하는 신경망과 탐색용 표준편차 등이 사용됩니다.
위 그림은 이들을 행동 분포로 묶어 표현한 개념도이며 모든 파라미터를 개별 노드로 그린 것은 아닙니다.
Critic은 가치 추정을 출력하며 보상 함수를 대신 정의하지 않습니다.
이 예시는 20장에 신경망이 이미 있다는 뜻이 아닙니다.

## 3. 20번 파일의 실제 실행 구조

![20_base_env.py 설정·랜덤 행동·환경 step·로그 루프](03-lesson20-structure.png)

20장은 관측을 반환받지만 다음 행동 생성에 사용하지 않습니다.
매번 `torch.randn()`으로 새 행동을 뽑고 결과를 로그로 기록합니다.
환경·보상·종료 처리가 작동하는지 확인하는 단계입니다.

## 4. env.step()과 물리 스텝의 관계

![행동 처리·물리 스텝 두 번·보상·종료·리셋·관측 반환 순서](04-environment-step.png)

기본 환경 4개는 같은 환경 step 안에서 함께 진행합니다.
종료 조건을 만족한 환경만 초기화하며 다른 환경은 계속 진행합니다.

| 단위 | 20장 설정 | 의미 |
|---|---|---|
| 물리 step | 1/120초 | 물리 엔진을 한 번 진행 |
| 환경 step | 물리 step 2회 · 1/60초 | 행동 적용 후 결과를 한 번 반환 |
| 에피소드 | 최대 5초 · 약 300 환경 step | 초기화부터 종료까지의 시도 |
| 데모 상한 | 2000 환경 step | 현재 스크립트 실행 종료 기준 |
| 학습 iteration | 20장에는 없음 | 실제 학습 실행기의 경험 수집·업데이트 단위 |

종료 플래그와 보상은 끝난 에피소드의 결과일 수 있지만,
자동 리셋된 환경의 반환 관측은 다음 에피소드 초기 상태일 수 있습니다.
위 그림은 주 제어 흐름을 요약했으며 recorder 등 부가 처리 경로는 생략했습니다.

## 무엇을 추가하면 실제 학습이 되는가?

20장의 환경을 학습기·래퍼에 연결하고, 정책 신경망과 PPO 설정을 전달합니다.
학습 실행기가 정책 행동으로 경험을 모으고 가중치를 업데이트합니다.
튜토리얼 24장에서 사용하는 `OnPolicyRunner`와 `runner.learn()`이 이 연결에 해당합니다.
