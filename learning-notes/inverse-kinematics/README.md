# 역기구학 · IK / Jacobian / DLS

**역기구학(Inverse Kinematics)은 말단의 목표 위치·방향을 만족하는 관절 구성을 찾는 계산이다.**
기구의 구조와 관절 한계, 시작 관절 상태 등이 해에 영향을 준다.

## FK와 IK 비교

| 구분 | 입력 → 출력 |
|---|---|
| 정기구학 · FK | 관절 상태 → 말단 포즈 |
| 역기구학 · IK | 목표 말단 포즈 → 관절 구성 |

FK는 구조와 베이스 포즈·관절 상태가 고정되면 결과가 정해진다.
IK는 같은 손끝 포즈를 만드는 팔 자세가 여러 개일 수 있고, 목표가 도달 범위 밖이면 해가 없을 수도 있다.
7관절 팔로 6자유도 말단 포즈를 제어하면 여유 자유도가 생길 수 있지만,
관절 한계·특이점·충돌 등의 조건에 따라 가능한 해는 달라진다.

## 미분 IK — 현재 위치에서 반복적으로 접근

Jacobian `J(q)`는 현재 관절 상태 주변에서 관절 변화와 말단 변화의 관계를 표현한다.

$$
\Delta x\approx J(q)\Delta q
$$

$$
\begin{bmatrix}v\\\omega\end{bmatrix}=J(q)\dot q
$$

`v`는 말단 선속도, `ω`는 각속도다.
팔 관절 7개로 위치·방향을 제어하는 13번 예제의 Jacobian은 6×7이다.
정사각 행렬이 아니므로 단순한 `J⁻¹`을 사용하는 계산으로 이해하면 안 된다.

미분 IK는 다음 과정을 반복한다.

1. 현재 말단 포즈와 목표의 오차를 구한다.
2. 현재 관절 상태의 Jacobian을 읽는다.
3. 작은 관절 변화 Δq를 계산해 관절 목표를 만든다.
4. 관절을 움직이고 갱신된 상태에서 다시 계산한다.

현재 상태 주변의 근사이므로 한 번의 계산으로 임의의 먼 목표를 정확하게 해결하는 것은 아니다.

## DLS — 특이점 근처의 과도한 변화 완화

특이점에서는 Jacobian의 랭크가 낮아져 특정 방향으로 말단을 움직이기 어려워진다.
그 근처에서는 작은 말단 변화에도 큰 관절 변화가 요구될 수 있다.

DLS(Damped Least Squares)는 다음과 같이 감쇠 항을 넣는다.

$$
\Delta q=J^T(JJ^T+\lambda^2I)^{-1}\Delta x
$$

$$
q_{des}=q_{current}+\Delta q
$$

λ는 감쇠 크기다. 감쇠를 늘리면 큰 관절 변화가 완화되지만 목표 추종이 보수적이거나 덜 정확해질 수 있다.
DLS는 안정성을 개선하는 방법이며, 모든 목표의 수렴·관절 한계 만족·충돌 회피를 자동으로 보장하지 않는다.
가속도 제한이나 장애물 회피가 필요하면 별도의 제약·계획·제어 구성이 필요하다.

## 포즈 입력 7개와 오차 6개

Isaac Lab의 절대 포즈 명령은 `[x, y, z, qw, qx, qy, qz]`로 7개 값을 사용한다.
방향을 쿼터니언 4개로 표현하지만 회전 자유도는 3개다.
IK 내부의 포즈 오차는 위치 3개 + 회전 벡터 3개로 구성하며, 쿼터니언 성분 네 개를 그대로 빼서 사용하는 것과 다르다.

## 좌표계와 실제 제어

목표 포즈, 현재 말단 포즈, Jacobian의 성분은 같은 표현 좌표계로 맞춰야 한다.
13번은 현재 포즈를 `subtract_frame_transforms`로 베이스 기준으로 바꾼다.
예제의 베이스 축은 월드 축과 정렬되어 있다. 회전된 베이스에서는 Jacobian의 선속도·각속도 행도 같은 좌표계로 변환해야 한다.

IK가 계산하는 값은 관절 위치 **목표**다.
PD 등의 구동 제어가 관절을 실제로 움직이고, 물리 계산 결과를 다음 IK 입력으로 사용한다.

```text
말단 목표 + 현재 상태 → IK → 관절 목표 → 관절 제어 → 실제 상태
                         ↑                         │
                         └──── 상태 갱신 ──────────┘
```

현재 링크 프레임과 공구 TCP가 다르면 고정 오프셋을 고려해야 한다.
IK 결과만으로 작업 경로, 접촉 힘, 집기 성공까지 결정되는 것은 아니다.
